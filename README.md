# Лабораторія ймовірностей

**Відкрити онлайн: [probability-lab-krasavin.onrender.com](https://probability-lab-krasavin.onrender.com)**

Одна адреса для вчителя й учнів, нічого не потрібно встановлювати.
Безкоштовний сервер «засинає» після 15 хвилин без відвідувачів, тому перше відкриття після паузи може тривати до хвилини.

Навчальний веб-інструмент для уроків теорії ймовірностей у закладах загальної середньої освіти.
Поруч показує **теоретичну ймовірність**, обчислену за шкільними формулами, і **відносну частоту**,
отриману моделюванням випадкового експерименту. Графік збіжності наочно демонструє закон великих чисел.

## Можливості

- **Лабораторія**: монети (у тому числі нечесна монета), гральні кубики (1–4), урна з кулями двох кольорів
  (вибір з поверненням і без повернення); події «рівно k», «не менше k», «сума дорівнює s», «хоча б один», «помилка гравця» тощо.
  Точна ймовірність у вигляді нескоротного дробу, моделювання до 200 000 випробувань, графік збіжності зі смугою ±2σ,
  порівняння теоретичного й емпіричного розподілів, кілька серій на одному графіку, режим «Приховати теорію».
- **Поясни мені**: покрокове розв'язання з формулами комбінаторики, таблиця 6 × 6 для двох кубиків, перелік наслідків для монет.
- **Практика**: завдання трьох рівнів і запитання на подолання хибних уявлень; миттєва перевірка на сервері,
  підказка після першої помилки, розв'язання після другої, кнопка «Перевірити експериментом».
- **Завдання**: генератор паралельних варіантів з ключем відповідей; друк або збереження в PDF засобами браузера;
  «код набору» дає змогу відтворити ті самі варіанти.
- **Уроки**: п'ять сценаріїв уроків з кнопками, що одразу налаштовують потрібний експеримент.
- Адаптивний інтерфейс (комп'ютер, планшет, телефон, проєктор), світла і темна теми, збільшення шрифту, гарячі клавіші.
- Без бази даних, без реєстрації, без збирання персональних даних.

## Запуск

Потрібна Java 17 або новіша.

```bash
java -jar probability-lab.jar
```

Після запуску відкрийте http://localhost:8080. Учні в тій самій шкільній мережі відкривають адресу комп'ютера вчителя
(її видно в журналі запуску і в розділі «Довідка»), наприклад `http://192.168.1.15:8080`.
Порт можна змінити: `java -jar probability-lab.jar --server.port=9090`.

У Windows можна просто запустити `run.bat`.

## Збирання з вихідного коду

```bash
mvn package
```

Готовий файл: `target/probability-lab.jar`. Тести (JUnit): `mvn test`.

## Розгортання в інтернеті

Онлайн-версія працює на безкоштовному тарифі хостингу Render: https://probability-lab-krasavin.onrender.com
(регіон Франкфурт, контейнер Docker з цього репозиторію).

Щоб розгорнути власну копію, на Render створіть Web Service з цього репозиторію (мова Docker, безкоштовний план,
Health Check Path `/api/info`) або Blueprint із `render.yaml`. `Dockerfile` збирає програму Maven-ом і готує архів
класів (CDS), який зменшує час запуску. Безкоштовний сервіс «засинає» після 15 хвилин без запитів, і перше
відкриття після паузи триває довше.

## Будова

| Пакет | Призначення |
|---|---|
| `ua.problab.math` | точні дроби (`Fraction`), формули комбінаторики, форматування українською |
| `ua.problab.experiment` | моделі експериментів (монети, кубики, урна), точна теорія і пояснення |
| `ua.problab.simulation` | моделювання методом Монте-Карло, контрольні точки для графіка збіжності |
| `ua.problab.practice` | режим практики, банк запитань на розуміння, розпізнавання відповідей |
| `ua.problab.tasks` | шаблони задач і генератор паралельних варіантів |
| `ua.problab.web` | REST API для веб-інтерфейсу |
| `src/main/resources/static` | веб-інтерфейс (HTML, CSS, JavaScript без сторонніх бібліотек) |

### API

| Метод | Адреса | Що робить |
|---|---|---|
| GET | `/api/catalog` | перелік експериментів і подій |
| POST | `/api/theory` | точна ймовірність і покрокове пояснення |
| POST | `/api/simulate` | моделювання N випробувань |
| GET | `/api/practice/next?level=1..3` | нове завдання для учня |
| POST | `/api/practice/check` | перевірка відповіді |
| POST | `/api/tasks/generate` | паралельні варіанти з ключем |
| GET | `/api/info` | адреси для під'єднання учнів |
