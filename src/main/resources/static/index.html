    Позначення

    • P(A) = mn — ймовірність події A: m сприятливих з n рівноможливих наслідків.
    • W(A) = MN — відносна частота: подія відбулася M разів у N випробуваннях.
    • Смуга ±2σ на графіку показує, у яких межах зазвичай коливається частота при даному N. Вона звужується зі зростанням N — так виглядає закон великих чисел.
